# ⚡ Fullstack React + CodeIgniter 4 Client App

A modern, responsive client-side web application built with **React**, **Vite**, and **Tailwind CSS v4**. Integrated with CodeIgniter 4 REST API for real-time CRUD operations.

## ✨ Features
- 🔄 **Realtime CRUD Operations:** Create, Read, Update, and Delete post data.
- 🔍 **Instant Search Filter:** Realtime client-side search by title or content.
- 🎨 **Modern Dark UI:** Styled with Tailwind CSS v4.
- 🚀 **High Performance:** Powered by Vite & React Hooks.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js (Vite)
- **Styling:** Tailwind CSS v4
- **HTTP Client:** Fetch API (REST API Integration)
